# 宇科連70 タイムテーブル

第70回宇宙科学技術連合講演会（2026年11月10日〜13日、宇都宮）のタイムテーブルアプリです。
音楽フェスのタイムテーブルアプリのように、聴きたいセッションを選んでマイスケジュールを作り、
当日はスマホで見ながら会場を移動できます。

**公開URL: https://fu-ji-p.github.io/ukaren70/**

> **このアプリは個人が作成した非公式ツールで、宇科連（宇宙科学技術連合講演会）および主催者とは関係ありません。**
> プログラムは公開情報をもとに作成しており、変更が反映されていない場合があります。最新情報は公式サイトをご確認ください。

サーバーもログインも不要です。選択内容は使っているブラウザの中（localStorage）にだけ保存されます。

> **当日使う端末（スマホ）で選択することをおすすめします。** 選択内容は端末・ブラウザごとに別々に保存され、
> 同じ Google アカウントで Chrome にログインしていても自動では同期されません。
> パソコンで作った場合は、⚙ 設定の「リンクをコピー / 共有」でスマホに送るか、JSON を書き出して読み込んでください。

## 使い方

1. **タイムテーブル** で日付タブを選び、横にスクロールして会場を見ます（横軸 = 会場、縦軸 = 時刻）。
   会期中は赤い線が現在時刻を示し、開いた時点でその日のタブが選ばれます。
2. セッションのカードをタップすると詳細（会場・建物・司会・講演一覧）が開きます。
   **「＋ セッション全体をマイスケジュールに追加」** でセッションごと選択します。もう一度押すと解除です。
   講演の左の **＋** を押すと、その講演 1 件だけを追加できます（講演の時刻はセッション時間を講演数で等分した目安）。
   セッション全体を選んだ状態で講演の ✓ を外すと、残りの講演が個別選択に切り替わります。
3. 上部の **マイスケジュール** で、選んだセッションが日付ごとに時系列で並びます。
   - 同じ時間帯に 2 件以上選ぶと **重複** バッジが付きます（選ぶこと自体はできます）。
   - ライトキューブ宇都宮 ⇄ TKP ガーデンシティ宇都宮 など建物をまたぐときは **建物移動** の注記と空き時間が出ます。
4. **印刷** ボタン（または Cmd/Ctrl+P）で A4 縦に印刷できます。日付ごとに改ページし、講演一覧も載ります。
5. 検索欄にキーワード（セッション名・講演題目・著者・司会、空白区切りで AND）を入れると該当カードが強調されます。
6. 右上の **⚙ 設定** から、別の端末へ送るリンクのコピー/共有、全選択のクリア、JSON の書き出し/読み込みができます。
   リンクをスマホで開くと「読み込みますか？」の帯が出るので「読み込む」を押してください。

動作確認用に `?now=2026-11-10T10:30` のようなクエリで現在時刻（JST）を偽装できます。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # Vitest
npm run build    # 型チェック + dist/ 生成
```

- Vite + React + TypeScript、UI ライブラリなし（素の CSS）。
- `main` への push で GitHub Actions がテスト→ビルド→GitHub Pages にデプロイします。
- 仕様の詳細は [docs/SPEC.md](docs/SPEC.md)。

## データの更新

プログラムは `data/program.json` にあり、ビルド時に取り込まれます。
更新手順は [docs/SPEC.md 第4章](docs/SPEC.md#4-データ更新手順) を参照してください。要点は次の通りです。

1. 公式 PDF から `scripts/parse_sessions.py` を参考にセッション・講演を抽出し、`data/program.json` を更新する。
2. `id` の重複や同一会場での時間重複がないことを確認する（`id` を変えると利用者の選択が消えるので注意）。
3. `npm test && npm run build` を通して `git push origin main` する。数十秒後に公開ページに反映される。
